# Welcome to the PS3Sweeper+!
*This game is based of the [Minesweeper Plus](https://jorel-simpson.itch.io/minesweeper-plus) game made by Jorel Simpson. Please, play the original game to support the original author of the Minesweeper Plus.*\
Isn't it the most awesome minesweeper game to play on YOUR PS3? Well, I hope so! With multiple chapters, multiple routes, and much more upon awaits you in this simple homebrew, made by one person! Currently, this version only contains first chapter and the main route among many, but it's at least better, than nothing, right?

Don't like the adventure? You can always count on free play! Customize your most finest game of minesweeper. It may be relaxing, it may be HARDCORE. Free choice, Free play!

Please be aware, that on RPCS3 or aPS3e, the game is not optimized well and may halt any second! On aPS3e it may halt almost immediately. RPCS3 can handle the game, but freeze may occur (rarely). The game was optimized to work with actual PS3 consoles, and there is nothing I can do about it.

NOTE: The Source code should be available RIGHT AFTER 1 month after the INITIAL release has been made. Thanks for understanding.
